# המזכירה שלי – אפליקציית Android

אפליקציית תזכורות ומשימות בעברית. התזכורות מגיעות כהתראה בטלפון גם כשהאפליקציה סגורה.

## איך מקבלים קובץ APK להתקנה

### דרך א׳: GitHub (בלי להתקין כלום, מומלץ)
1. נכנסים ל-github.com, נרשמים בחינם, ולוחצים **New repository**. שם: `HaMazkira`, ולוחצים **Create repository**.
2. בעמוד המאגר לוחצים **uploading an existing file**, וגוררים את **כל התוכן** של התיקייה HaMazkira (כולל התיקיות `app`, `gradle`, `.github`). לוחצים **Commit changes**.
   * עדיף לעשות את זה ממחשב. אם התיקייה `.github` לא עלתה (היא מוסתרת לפעמים), יוצרים קובץ חדש בשם `.github/workflows/build.yml` ומדביקים בו את התוכן מהקובץ שבתיקייה.
3. עוברים ללשונית **Actions**. הבנייה מתחילה לבד ולוקחת בערך 5 דקות.
4. כשמופיע וי ירוק, נכנסים לריצה ומורידים את **HaMazkira-apk** מתחתית העמוד. בתוך קובץ ה-zip נמצא `app-debug.apk`.

### דרך ב׳: Android Studio במחשב
פותחים את התיקייה HaMazkira ב-Android Studio, מחכים לסנכרון, ואז **Build › Build APK(s)**.
אפשר גם לחבר את הטלפון בכבל וללחוץ ▶ Run.

## התקנה בטלפון
1. מעבירים את `app-debug.apk` לטלפון ופותחים אותו.
2. מאשרים "התקנה ממקורות לא ידועים" כשהטלפון מבקש.
3. Google Play Protect עשוי להזהיר שהאפליקציה לא מוכרת. זה צפוי לאפליקציה שבנית בעצמך. לוחצים "התקן בכל זאת".
4. בפתיחה הראשונה מאשרים **התראות**.

## מה יש באפליקציה
* היום שלי, יומן חודשי, חיפוש (כפתור הזכוכית המגדלת למעלה) והגדרות
* **פנקס רשומות**: כותבים רשומות חופשיות (השורה הראשונה היא הכותרת). לכל רשומה אפשר לסמן **"להזכיר לי"** עם תאריך ושעה, והיא תגיע כהתראה בטלפון. כפתור "עם תזכורת" מציג רק רשומות שמחכה להן תזכורת
* **מחיקה** של כל רשומה וכל משימה בכפתור "מחק" שבכרטיס (לוחצים פעמיים, כדי שלא יימחק בטעות)
* הוספה בקול בעברית (כפתור המיקרופון) או בכתיבה חופשית: "תזכירי לי ביום חמישי בשעה 4 לקחת את הרכב לטיפול"
* תזכורות בזמן, 10 / 30 דקות, שעה או יום לפני, כמה ביחד
* משימות חוזרות: יומי, שבועי, חודשי, שנתי
* כפתורי **בוצע** ו**דחה 10 דק׳** ישירות בהתראה
* חשיבות: רגיל / חשוב / דחוף
* שליחה ל-WhatsApp והוספה ל-Google Calendar
* התזכורות חוזרות לפעול אחרי הפעלה מחדש של הטלפון
* גיבוי ושחזור בהגדרות

## טיפים
* בחלק מהטלפונים (Xiaomi, Samsung, Huawei) כדאי להגדיר את האפליקציה כ**לא מוגבלת** בהגדרות הסוללה, כדי שהתזכורות יגיעו בזמן.
* המשימות שמורות בטלפון עצמו. שלח לעצמך גיבוי מדי פעם (הגדרות › שליחת גיבוי).

## מבנה הקוד
* `app/src/main/assets/index.html` – המסכים והלוגיקה
* `MainActivity.java` – החלון, זיהוי דיבור, פתיחת קישורים
* `AlarmStore.java`, `AlarmReceiver.java` – תזמון והצגת התראות
* `ActionReceiver.java` – כפתורי בוצע / דחה בהתראה
* `BootReceiver.java` – החזרת התזכורות אחרי הפעלה מחדש
